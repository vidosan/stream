# 📺 PythonProject1 — Полная инструкция по использованию

## 📁 Что внутри проекта

В директории `C:\PythonProject1` находится набор инструментов для работы с экраном:

| Файл | Назначение |
|------|-----------|
| **stream.py** | 🖥️ **Сервер трансляции экранов** — точка запуска (весь код в `stream_project/`) |
| **stream_project/** | 📦 Пакет с кодом, конфигом и тестами сервера (см. структуру ниже) |
| **record.py** | 🎥 Запись экрана (базовая версия) |
| **record_0.1.py** | 🎥 Запись экрана с расписанием |
| **record_0.2.py** | 🎥 Запись экрана с прогресс-баром и детекцией движений |
| **stream.spec** | 🔧 Конфиг для сборки в .exe (PyInstaller) |

**Методы захвата** (выбираются в окне при запуске): dxcam (быстрый, все мониторы — по камере на каждый), dxcam1 (только монитор 1, старый проверенный), mss (все мониторы, стандартный). FFmpeg и d3dshot удалены из программы.

### 📦 Структура пакета `stream_project/`

Раньше всё лежало в одном `stream.py` (1246 строк). Теперь весь код сервера
внутри пакета `stream_project/`:

```
stream_project/
├── __init__.py
├── __main__.py          запуск пакетом: python -m stream_project
├── main.py              точка входа: выбор метода захвата + запуск сервера
├── config.py            порт, пароль, качество JPEG, FPS, флаг управления
├── servers.json         ⚙️ список серверов (правится здесь)
├── deps.py              опциональные зависимости (dxcam, mss)
├── logs.py              настройка логирования
├── monitors.py          определение мониторов (MONITOR_CONFIGS, find_monitor)
├── frames.py            хранилище последних кадров каждого монитора
├── control/             управление мышью и клавиатурой
│   ├── win32.py         инъекция ввода через Win32 SendInput (ctypes)
│   ├── events.py        разбор событий из браузера, смещение монитора
│   └── forward.py       пересылка ввода на удалённые серверы
├── capture/             методы захвата экрана
│   ├── dxcam_capture.py dxcam: поток на каждый монитор + watchdog
│   ├── mss_capture.py   mss: все мониторы в одном цикле
│   └── selftest.py      самопроверка методов (--test)
├── web/                 веб-слой
│   ├── app.py           Flask: /, /view, /screen, /proxy, /input, /ws
│   └── pages.py         HTML-страницы (сетка карточек и полный экран)
└── tests/               тесты
    ├── test_input_pipeline.py  логика ввода (без реальной мыши)
    ├── test_capture.py         захват mss и dxcam
    ├── test_control.py         интеграция: HTTP, WebSocket, пароль, MJPEG
    └── test_dxcam*.py          старые отладочные скрипты dxcam
```

В корне остались только `stream.py` (точка запуска) и `stream.spec` (сборка).
`stream.py` нужен именно в корне: на него ссылаются ярлыки, инструкция и
PyInstaller (`Analysis(['stream.py'])`) — внутрь пакета его положить нельзя,
иначе сломается сборка `.exe`.

Запускать можно двумя способами — оба равнозначны:

```bash
python stream.py            # через лаунчер в корне (обычный способ)
python -m stream_project    # напрямую пакетом
```

### 🧪 Тесты

```bash
python -m stream_project.tests.test_input_pipeline   # логика ввода — 12 проверок
python -m stream_project.tests.test_capture          # захват mss и dxcam — 4 проверки
python -m stream_project.tests.test_control          # HTTP/WebSocket/пароль/MJPEG — 19 проверок
python stream.py --test                              # самопроверка методов захвата
```

## 🖥️ ЧАСТЬ 1: stream.py — Трансляция экранов в браузер

### 🎯 Что это делает

Захватывает экраны ПК и показывает их в реальном времени через веб-браузер. Можно смотреть несколько мониторов одновременно, включая удалённые серверы.

### 📋 Требования

Установите зависимости (откройте командную строку в папке проекта):

```bash
pip install flask flask-sock mss opencv-python numpy requests
```

### 🚀 Как запустить сервер

**Шаг 1:** Откройте командную строку в папке проекта:
```
cd C:\PythonProject1
```

**Шаг 2:** Запустите сервер:
```bash
python stream.py
```

**Шаг 3:** В браузере откройте:
- Локально: `http://localhost:8000`
- С другого ПК: `http://<IP-вашего-ПК>:8000`

### 🖱️⌨️ Управление мышью и клавиатурой (по умолчанию ВЫКЛЮЧЕНО)

Позволяет управлять серверным ПК прямо из окна браузера: двигать мышь, кликать,
печатать. Работает на всех мониторах.

**Включение** — переменная окружения `STREAM_CONTROL=1`. 4 способа:

**Способ 1 — .bat-файл (рекомендуется)**
Файл `stream_control.bat` в корне проекта:
```
stream_control.bat          # управление ВКЛ
stream_control.bat --test   # только тест захвата
```

**Способ 2 — только на этот запуск (PowerShell)**
```powershell
$env:STREAM_CONTROL = "1"; python stream.py
```

**Способ 3 — навсегда для пользователя**
```powershell
setx STREAM_CONTROL 1
# После этого перезапустите консоль
python stream.py
```
Отключить: `setx STREAM_CONTROL 0`

**Способ 4 — изменить значение по умолчанию в коде**
В `stream_project/config.py` строка 47:
```python
CONTROL_ENABLED = os.environ.get('STREAM_CONTROL', '1') == '1'  # было '0'
```
После этого сервер включится сразу, без переменных окружения.

> ⚠️ Управление должно быть включено `STREAM_CONTROL=1` **и на том ПК, откуда
> смотрите, и на том, которым управляете** — ввод пересылается по тому же пути,
> что и видео.

**Как пользоваться:**

1. На странице нажмите кнопку **«Режим: Просмотр»** → станет **«Режим: Управление»** (красная).
2. **Кликните по нужному монитору** — карточка обведётся красным и получит фокус.
   Первый клик только выбирает монитор, чтобы случайно ничего не нажать.
3. Теперь мышь и клавиатура идут на тот ПК. Клавиша **Esc** снимает фокус.
4. Двойной клик по карточке в режиме управления открывает **полный экран** с управлением.

**Особенности:**

- Управление должно быть включено (`STREAM_CONTROL=1`) **и на том ПК, откуда смотрите,
  и на том, которым управляете** — ввод пересылается по тому же пути, что и видео.
- Для своей машины ввод применяется сразу, без пересылки по сети.
- При уходе со страницы/потере фокуса все зажатые клавиши автоматически отпускаются.
- Клавиши F5, F12 и т.п. перехватываются, пока монитор в фокусе — это нормально для
  удалённого управления. Esc снимает фокус, после чего браузер работает как обычно.
- Управление идёт через **WebSocket** (`/ws`), плюс есть HTTP-точка `/input`
  для пересылки между серверами.

⚠️ **Безопасность:** при включённом управлении любой, кто знает адрес и пароль,
получит полный контроль над ПК. Обязательно задайте `STREAM_PASSWORD` и не
включайте управление без необходимости.

### ⚙️ Настройка удалённых серверов

Список серверов хранится в `stream_project/servers.json` — его можно править без пересборки:

```json
[
  {
    "name": "138",
    "host": "192.168.3.138",
    "port": 8000,
    "monitors": 2
  },
  {
    "name": "2",
    "host": "192.168.3.2",
    "port": 8000,
    "monitors": 2
  },
  {
    "name": "1",
    "host": "192.168.3.1",
    "port": 8000,
    "monitors": 2
  }
]
```

**Параметры:**
- `name` — имя сервера (отображается на странице)
- `host` — IP-адрес ПК с запущенным stream.py
- `port` — порт (по умолчанию 8000)
- `monitors` — количество мониторов на этом ПК

### 🌐 Как работает веб-интерфейс

1. **Главная страница** — сетка карточек с экранами всех мониторов
2. **Перетаскивание** — карточки можно менять местами мышью
3. **Двойной клик** — открыть монитор на полный экран
4. **Живое обновление** — экран обновляется до 15 кадров в секунду (`MAX_FPS` в `stream_project/config.py`)

### 🔧 Как настроить несколько ПК

**На каждом ПК, экран которого нужно смотреть:**
1. Скопируйте папку `stream_project` и файл `stream.py`
2. Запустите: `python stream.py`
3. Сервер запустится на порту 8000

**На ПК для просмотра (клиент):**
1. В `stream_project/servers.json` укажите IP всех серверов
2. Запустите: `python stream.py`
3. Откройте браузер: `http://localhost:8000`

## 🎥 ЧАСТЬ 2: Запись экрана

В проекте есть 3 версии программы записи. Используйте **record.py** — самая простая и стабильная.

### 📋 Требования

```bash
pip install mss opencv-python tkinter
```

**Для конвертации в MP4:** нужен `ffmpeg` — скачайте с https://www.gyan.dev/ffmpeg/builds/

### 🚀 Запуск

```bash
python record.py
```

### ⚙️ Параметры

| Параметр | Описание |
|----------|----------|
| **Разрешение** | Размер захвата (по умолчанию 1280x720) |
| **Качество** | Низкое / Среднее / Высокое |
| **Авто-конвертация** | Автоматически конвертирует AVI → MP4 |

### 💾 Где сохраняются записи

Папка `recordings/` в директории проекта.

### ⚠️ Особенности

- Файлы автоматически делятся по **1 часу**
- Формат AVI → при включённой конвертации автоматически в MP4
- MP4 на **80-90% меньше** по размеру
- При закрытии программы запись останавливается

## 🔧 ЧАСТЬ 3: Сборка в .exe (PyInstaller)

```bash
pip install pyinstaller
pyinstaller stream.spec
```

Результат: `dist\stream.exe` — готовая программа.

**Важно:** после сборки рядом с `stream.exe` должен лежать файл `servers.json` —
программа ищет его в первую очередь рядом с собой. Положите рядом ту копию,
которая нужна на этом ПК.

## 🆘 Возможные проблемы и решения

### ❌ Ошибка: «No module named 'mss'»
```bash
pip install mss
```

### ❌ Ошибка: «Port 8000 already in use»
Измените порт в `stream_project/main.py` (константа `PORT`) на другой (например, 8080).

### ❌ Сервер не виден с другого ПК
1. Проверьте брандмауэр Windows — разрешите порт 8000
2. Проверьте, что оба ПК в одной сети
3. Убедитесь, что на сервере запущен stream.py
